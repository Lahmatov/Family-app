# Family App

Семейное iOS-приложение: бюджет, дети, документы, цели, планирование. Главное требование — безопасность.

**Сейчас готово (этап 1):** аккаунты с обязательной 2FA, Face ID, семьи и роли, подтверждение критичных действий вторым админом, расходы и бюджет с фото чеков, три языка (ru / en / pt-PT).
