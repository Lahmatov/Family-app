# Хостинг и сервисы для онлайн-работы

Решение на старте: **Supabase Cloud, бесплатный тариф, регион ЕС (Франкфурт)**. Приложение уже написано под него, ничего поднимать и администрировать не нужно. Дальше можно перейти на платный тариф или свой сервер: миграции и код те же.

## Что даёт и чем ограничен бесплатный Supabase

| Ограничение | Значение | Что делаем |
|---|---|---|
| База | 500 МБ | Текстовых данных семье хватит на годы |
| Файлы | 1 ГБ | Фото чеков уже сжимаются до ~2000 px JPEG; позже вынести тяжёлые фото в S3-совместимое хранилище или платный тариф |
| Трафик | 5 ГБ в месяц | Хватает для семьи |
| Простой | проект **засыпает после недели без активности** | Семья заходит чаще; на случай отпуска настроить пинг (cron в GitHub Actions) |
| Проекты | 2 бесплатных | Один — рабочий, второй — тестовый (staging) |
| Бэкапы | на бесплатном тарифе автоматических нет (проверь на странице тарифов) | Делаем свои, см. ниже |

Источники: [Supabase Pricing 2026 (Jetadmin)](https://www.jetadmin.io/blog/supabase-pricing-2026-guide-to-plans-limits-and-real-world-costs/), [Supabase Free Plan 2026 (Costbench)](https://costbench.com/software/database-as-service/supabase/free-plan/). Цифры меняются: перед запуском сверь с официальной страницей тарифов.

## Нужен ли Kafka? Нет

Kafka нужен, когда тысячи событий в секунду между десятками сервисов. У семейного приложения нагрузка в тысячи раз меньше, и всё нужное уже есть в Supabase:

| Задача | Чем решаем | Стоимость |
|---|---|---|
| Живые обновления между телефонами (общий список, новая трата) | Supabase Realtime (WebSocket) | входит |
| Фоновые задачи по расписанию (курсы валют, напоминания, пинг) | `pg_cron` в Postgres | входит |
| Очередь задач (разбор ссылок квартир, отправка писем) | `pgmq` — очередь внутри Postgres | входит |
| Серверная логика (парсинг объявлений, курсы ЕЦБ) | Edge Functions (Deno) | входит, есть лимит вызовов |
| Файлы и фото | Supabase Storage | см. лимит выше |

Принцип: один Postgres вместо зоопарка. Каждый лишний сервис — это ещё один взломанный пароль, ещё один счёт и ещё одно место, где могут лежать данные детей.

## Что ещё нужно подключить

### 1. Почта (для подтверждения email, сброса пароля, приглашений)
Встроенная почта Supabase только для проверки: у неё очень жёсткий лимит. Для реального использования подключаем свой SMTP:

| Сервис | Бесплатно | Заметка |
|---|---|---|
| [Brevo](https://www.brevo.com/free-smtp-server) | 300 писем в день | самый большой бесплатный лимит, SMTP + API |
| [Resend](https://resend.com/pricing.md) | 3000 в месяц, но не больше 100 в день | удобный API, 1 домен |
| [Mailgun](https://www.courier.com/providers/compare/mailgun-vs-mailjet/) | 100 в день | можно, но выгоднее Brevo |

Рекомендую **Brevo**. Нам нужны единицы писем в день. Чтобы письма не попадали в спам, нужен **свой домен** (SPF, DKIM, DMARC): это ~€10 в год и единственная обязательная трата. Домен пригодится ещё для universal links вместо `familyapp://`.

### 2. Уведомления
- **Локальные уведомления** (бесплатно, без сервера): прививки, платежи по кредиту, сроки документов, цели. Приложение само ставит напоминания на телефоне из своих данных. Покрывает почти всё нужное.
- **Push с сервера** (например, «партнёр добавил расход») требует APNs, а значит платного Apple Developer ($99 в год). Это единственная причина покупать его до TestFlight.

### 3. Резервные копии (обязательно, на бесплатном тарифе их нет)
Ночной `pg_dump` в GitHub Actions, шифрование ключом `age` и сохранение копии в приватное хранилище (приватный репозиторий или бесплатный S3-совместимый бакет). Файлы Storage копируем отдельно. Раз в квартал проверять восстановление: бэкап, который ни разу не восстанавливали, бэкапом не считается. Ключ восстановления хранить на бумаге.

### 4. Наблюдение
- Проверка доступности: бесплатный UptimeRobot или Better Stack, плюс пинг, чтобы проект не засыпал.
- Ошибки приложений: Sentry (есть бесплатный тариф). Но это сторонний сервис, куда уходят данные о сбоях: включать только с вырезанием персональных данных, либо обойтись логами Supabase.

### 5. Серверные функции, которые мы напишем
- Разбор страницы объявления по ссылке (Idealista, Imovirtual…) с защитой от SSRF: только https, запрет внутренних адресов, лимит размера и времени. Сайты могут блокировать парсинг и менять вёрстку: ручной ввод остаётся запасным путём.
- Ежедневные курсы валют ЕЦБ в таблицу курсов.
- Очистка файлов в Storage, на которые нет записей.

## Окружения

| Окружение | Где | Для чего |
|---|---|---|
| Локально | `supabase start` (Docker) | разработка и тесты |
| Staging | второй бесплатный проект | проверка миграций перед рабочей базой |
| Production | первый проект | семья |

Миграции из `supabase/migrations` накатываются командой `supabase db push`. Перед накаткой на production — всегда на staging.

## Когда стоит платить

| Триггер | Что делать |
|---|---|
| Хочется не думать про простой и бэкапы | Supabase Pro, $25 в месяц (бэкапы, нет засыпания) |
| Закончились 1 ГБ под фото | S3-совместимое хранилище или Pro |
| Нужны push-уведомления или TestFlight | Apple Developer, $99 в год |
| Захотелось полный контроль | свой сервер (Mac mini + Tailscale или VPS) с теми же миграциями |
