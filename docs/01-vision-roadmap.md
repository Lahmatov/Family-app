# Видение и роадмап

Семейное «супер-приложение» для iPhone. Всё, что касается семьи, лежит в одном месте и защищено так, чтобы этим было не страшно пользоваться для документов и медданных детей.

## Решения, принятые на старте

| Вопрос | Решение |
|---|---|
| Платформа | Только iPhone, нативно (SwiftUI, iOS 17+) |
| Бэкенд | Supabase (Postgres + RLS, Auth, Storage). Хостинг выберем позже: Mac mini дома с Tailscale или VPS в ЕС, код одинаковый |
| Регион данных | ЕС (GDPR: в приложении будут медданные детей) |
| Языки | Русский, английский, португальский (Португалия), выбор в настройках iPhone |
| Валюта по умолчанию | EUR, у операции может быть любая валюта |
| Вход | Свой аккаунт у каждого, email + пароль, **обязательная 2FA (TOTP)**, Face ID на приложение |
| Критичные действия | Подтверждает **второй админ** (принцип «четырёх глаз») |
| Квартиры | Португалия: Idealista, Imovirtual, Casa Sapo, SUPERCASA, RE/MAX |
| Прививки | Национальный календарь Португалии (PNV) |

### Что предлагаю добавить
- Сроки документов: паспорт, ВНЖ, загранпаспорт, страховки, техосмотр (IPO), с напоминаниями.
- Подписки и регулярные платежи (автоматически попадают в бюджет).
- Списки покупок (общие, в реальном времени).
- Экстренная медкарта ребёнка: группа крови, аллергии, лекарства, контакты врачей.
- Гарантии и чеки на технику.
- Машина: ТО, страховка, расходы.
- Дни рождения и важные даты.
- Виджеты на экран iPhone и Siri Shortcuts («добавь расход 20 евро продукты»).
- Импорт банковской выписки (CSV/OFX).
- Курсы валют автоматически (ЕЦБ) через Edge Function.

## Этапы

1. **Фундамент + бюджет** (этот PR): схема БД с RLS, 2FA, роли, подтверждения, бюджет, iOS-приложение, CI, тесты.
2. Цели, задачи с обсуждениями, заметки, пуш-уведомления.
3. Дети.
4. Квартиры (парсер ссылок в Edge Function, карта MapKit, ранжирование).
5. Кредиты ✅ (отпуск пока не сделан).
6. Зашифрованный сейф (E2E) ✅, см. `08-vault.md`.
7. Полный пентест, харденинг, TestFlight; затем по кругу.

Каждый этап: сначала схема и RLS с pgTAP-тестами, потом доменная логика в `FamilyCore` с unit-тестами, потом UI с UI-тестами.
